# Описание мок-данных для эндпоинта GET /stats

## Структура ответа

```json
{
    "one_time_metrics": { ... },
    "forecast": { ... },
    "review_count": { ... },
    "review_time": { ... },
    "hourly_breakdown": { ... },
    "difficulty_distribution": { ... },
    "stability_distribution": { ... },
    "card_types": { ... }
}
```

---

## 1. `one_time_metrics`

**Описание:** Разовые метрики — общее время изучения за ВСЁ время существования аккаунта.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `total_study_seconds` | `int` | Общее время изучения в секундах. Суммарное время всех ревью пользователя с момента регистрации. | `45630` (= ~12.67 часа) |
| `total_reviews` | `int` | Общее количество повторов карточек. Всего раз, когда пользователь отвечал на карточки. | `1234` |

---

## 2. `forecast`

**Описание:** Прогноз повторений — сколько карточек будет нужно повторить в каждый из следующих 30 дней.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<ForecastPoint>` | Массив точек графика прогноза | — |

### ForecastPoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `date` | `string` | Дата в формате YYYY-MM-DD | `"2026-08-06"` |
| `count` | `int` | Количество карточек на повтор | `12` |

---

## 3. `review_count`

**Описание:** График повторений — сколько раз пользователь ответил по каждой категории в каждый из последних 30 дней.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<ReviewCountPoint>` | Массив точек с разбивкой по дням | — |

### ReviewCountPoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `date` | `string` | Дата в формате YYYY-MM-DD — день, когда были ревью | `"2026-07-07"` |
| `forgotten` | `int` | Количество ответов "Забыл" (рейтинг 1) — красный цвет | `3` |
| `hard` | `int` | Количество ответов "Сложно" (рейтинг 2) — жёлтый цвет | `2` |
| `good` | `int` | Количество ответов "Хорошо" (рейтинг 3) — жёлто-зелёный | `8` |
| `easy` | `int` | Количество ответов "Легко" (рейтинг 4) — зелёный цвет | `5` |

> **total** = `forgotten + hard + good + easy` = общее количество ревью за день

---

## 4. `review_time`

**Описание:** График времени — сколько секунд пользователь потратил на ревью в каждый из последних 30 дней.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<ReviewTimePoint>` | Массив точек с временем по дням | — |

### ReviewTimePoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `date` | `string` | Дата в формате YYYY-MM-DD | `"2026-07-07"` |
| `seconds` | `int` | Суммарное время в секундах. `900` секунд = 15 минут | `1200` |

---

## 5. `hourly_breakdown`

**Описание:** Продуктивность по часам суток — какой процент ответов был успешным (Хорошо + Легко) в каждом временном диапазоне.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<HourlyBreakdownPoint>` | Массив из 6 точек по 4-часовым диапазонам | — |

### HourlyBreakdownPoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `hour_range` | `string` | Диапазон часов `HH:HH-HH:HH`. 6 диапазонов по 4 часа | `"08:00-12:00"` |
| `percentage` | `float` | % успешных ответов (0-100). Высокий = хорошая продуктивность | `85.2` |

### 6 временных диапазонов

| Диапазон | Описание |
|----------|----------|
| `00:00-04:00` | Полночь — 4 утра. Поздняя ночь / раннее утро |
| `04:00-08:00` | 4 — 8 утра. Раннее утро |
| `08:00-12:00` | 8 — 12 дня. Утро / середина дня |
| `12:00-16:00` | 12 — 4 дня. День / середина дня |
| `16:00-20:00` | 4 — 8 вечера. Вечер |
| `20:00-24:00` | 8 — 12 ночи. Поздний вечер |

---

## 6. `difficulty_distribution`

**Описание:** Распределение карточек по сложности — сколько карточек в каждом диапазоне сложности (от 1 до 10).

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<DifficultyDistributionPoint>` | Массив точек по диапазонам сложности | — |

### DifficultyDistributionPoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `range_label` | `string` | Диапазон сложности `N-N+1`. От `1-2` (лёгкие) до `9-10` (сложные) | `"5-6"` |
| `count` | `int` | Количество карточек в этом диапазоне | `42` |

### Шкала сложности

| Диапазон | Описание |
|----------|----------|
| `1-2` | Самые лёгкие — материал, который пользователь помнит отлично |
| `2-3` | Очень лёгкие — легко запоминается |
| `3-4` | Лёгкие — большинство карточек |
| `4-5` | Ниже среднего — умеренная сложность |
| `5-6` | Средние — типичные карточки |
| `6-7` | Выше среднего — требуют внимания |
| `7-8` | Сложные — проблемные карточки |
| `8-9` | Очень сложные — трудно запоминаются |
| `9-10` | Самые сложные — максимум сложности |

---

## 7. `stability_distribution`

**Описание:** Распределение карточек по стабильности — через сколько дней карточка будет вспомнена с вероятностью 90%.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<StabilityDistributionPoint>` | Массив точек по диапазонам стабильности | — |

### StabilityDistributionPoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `range_label` | `string` | Диапазон дней, через который вероятность вспомнить = 90%. Чем больше дней — тем стабильнее знание | `"1-25 дней"` |
| `count` | `int` | Количество карточек в этом диапазоне | `15` |

### Шкала стабильности

| Диапазон | Описание |
|----------|----------|
| `1-25 дней` | Карточки, которые скоро забудут — критически важные для повторения |
| `25-50 дней` | Карточки, которые вспомнят через 1-2 месяца — умеренная стабильность |
| `50-100 дней` | Карточки, которые вспомнят через 2-3 месяца — хорошая стабильность |
| `>100 дней` | Карточки с долгосрочным запоминанием — отличная стабильность |

---

## 8. `card_types`

**Описание:** Типы карт — количество карточек каждого типа в колодах пользователя.

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `points` | `Array<CardTypePoint>` | Массив точек с типами карт | — |

### CardTypePoint

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `card_type` | `string` | Тип карты: `новые`, `изучаемые`, `изученные`, `отложенные` | `"новые"` |
| `count` | `int` | Количество карт данного типа | `10` |

### Типы карт

| Тип | Описание |
|-----|----------|
| `новые` | Новые карточки, которые пользователь ещё не изучал. Ожидают первого ревью |
| `изучаемые` | Карточки в процессе изучения. Проходят повторения по алгоритму интервального повторения |
| `изученные` | Карточки, которые пользователь успешно выучил. Проходят долгосрочное повторение |
| `отложенные` | Карточки, временно отложенные. Не участвуют в ревью до момента снятия отложенности |
